## 📘 Огляд

Цей репозиторій містить код для веб-сайту, який допомагає людям **знаходити
домівки для тварин** у притулку. Проект побудовано на базі шаблону
_vanilla-app-template_ з використанням сучасного фронтенду.
:contentReference[oaicite:2]{index=2}

---

## 🚀 Функціональність

✔ Сторінки з переліком тварин  
✔ Деталі кожної тварини  
✔ Можливість зв’язатися з притулком  
✔ Адаптивний дизайн для мобільних і десктопів

---

## 🧱 Стек технологій

Цей проєкт використовує:

- **HTML / CSS / JavaScript**
- **Vite** як збірник
- Swetalert2
- Swiper.js
- Accordeon.js
- Axios
